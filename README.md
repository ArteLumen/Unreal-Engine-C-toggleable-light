# Unreal-Engine-C-toggleable-light
A simple and lightweight Unreal Engine C++ actor component that automatically toggles a point light on and off when the player character enters a specific trigger zone.

Features
C++ Implementation: Written completely in C++ for optimal performance.

Proximity Trigger: Uses a USphereComponent to detect when the player approaches.

Blueprint Friendly: Functions are exposed to Blueprints using UFUNCTION(BlueprintCallable).
